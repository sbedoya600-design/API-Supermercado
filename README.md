# API Supermercado

API REST desarrollada con Node.js y Express para la gestión de productos de un supermercado.

## Tecnologías utilizadas

- Node.js
- Express
- JavaScript
- Postman
- Git
- GitHub

## Servicios disponibles

### GET /productos

Obtiene todos los productos registrados.

### GET /productos/:id

Obtiene un producto específico mediante su identificador.

### POST /productos

Permite registrar un nuevo producto.

### PUT /productos/:id

Permite actualizar la información de un producto existente.

### DELETE /productos/:id

Permite eliminar un producto existente.
